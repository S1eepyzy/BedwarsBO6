# BedwarsBO6

> ⚠️ **重要声明**
本仓库仅存放项目设计方案、Maven构建配置、ProGuard混淆规则、部署脚本与文档。
**核心业务源代码不予公开，仅分发经过混淆编译后的二进制Jar产物。**

## 项目简介
BedwarsBO6 是《Minecraft》起床战争服务端复刻项目。
本仓库不包含可直接运行的完整服务端程序，仅提供配置、方案文档与部署相关脚本。
想要运行服务端，你需要自行构建混淆后的Jar二进制文件。

## 仓库包含内容
- 项目规划方案文档 `plan*.md`
- Maven项目配置 `pom.xml`
- ProGuard代码混淆配置 `proguard‑bwbo6.pro`
- 部署相关配置文件

## 使用说明
1. 将自行编译混淆后的核心Jar包放置本地；
2. 使用 docker‑compose 完成容器部署，挂载本地混淆Jar；
3. 仅允许用于个人非商业私人服务器使用。
